Local FastAPI RAG API

This sample document lives in data/docs. The API chunks files in that folder
and retrieves the most relevant passages with BM25, then asks Ollama
(qwen2.5:0.5b by default) to answer using only that context.

How to chat without the API:
  ollama run qwen2.5:0.5b

How to chat with the API:
  POST /chat  — send a prompt straight to Ollama
  POST /ingest — rebuild the local BM25 index from data/docs
  POST /query — retrieve context, then generate an answer
